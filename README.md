# Тренажер по химии
Проект по веб-разработке на образовательную тематику. 
В созданном приложении можно:
* Сохранять в базу данных химические формулы и их названия
* Просматривать сохраненные формулы в удобном списке
* Сохранять изображения химических веществ и их названия
* Просматривать сохраненные изображения в формате галереи
* При необходимости, удалять сохраненные данные

## Как использовать

1. Скачать этот репозиторий или клонировать его
2. Перейти в '/chemistry_trainer/chemistry_proj' при помощи `cd`
3. `pip install -r requirements.txt`
4. `python manage.py runserver `

## Версии ПО

Предполагается использование версии 4.1.7 фреймворка Django. Для ее запуска вам понадобится интерпретатор Python версии 3.8, 3.9, 3.10, 3.11 или 3.12. Разработка велась на версии 3.9.
